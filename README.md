Sistema Escolar em JavaScript e PHP

Este projeto foi desenvolvido com o objetivo de praticar os principais conceitos da Programação Orientada a Objetos (POO), utilizando JavaScript e PHP.

Tecnologias Utilizadas

JavaScript
PHP
Programação Orientada a Objetos (POO)


Conceitos Aplicados

Herança
As classes `Aluno`, `Professor`, `Diretor` e `Funcionario` herdam características da classe `Pessoa`.

Polimorfismo
Cada classe possui seu próprio método `falar()`, exibindo mensagens diferentes.

Encapsulamento
A idade foi protegida utilizando atributos privados, permitindo acesso apenas através do método `getIdade()`.
